## 제작 범위

기존 R12 끝에서 R13을 연결해 3장 Q24~Q33, 5·6관장, F08 급류타기, F09 괴력운반, MAP09~12, 몬스터 #091–102, 선택 의뢰 SQ3-01~08을 구현한다. 우선 메인 이동과 저장을 연결하고 다음으로 전투·동료·서브 퀘스트·아트를 붙인다.

7·8관장·폭포 오르기·잠수·본부 최종전·#103 이후는 이번 요청에 포함하지 않는다. 예고 대사와 막힌 경계만 두고, 후속 기획이 확정된 것처럼 만들지 않는다.

## 기존 구현과 연결할 지점

- maps5.js의 M.searoute에 기존 ch2_end 연출과 이어지는 출구가 있다. 2장 완료 플래그와 엔딩 시청 기록은 보존하고, 본 사람은 반복 엔딩·새 게임 없이 R13으로 나가게 한다.
- 현재 탐험 기술 키는 vine/push/echo/ripple/magnet/smash/surf다. F08·F09는 기획 번호이므로 실제 새 키를 current/haul 등 일관된 이름으로 매핑하고 field.js의 순서·적성·지원 호출·상호작용·되돌리기·구조를 함께 확장한다.
- 지도 페이지 수집은 field.js의 CHS()에서 현재 G.CH1·G.CH2를 다룬다. G.CH3 및 현재 장의 목표·지도 페이지 선택도 연결한다. 아이템만 추가하고 화면에 3장 지도가 안 나타나는 상태를 피한다.
- 신규 맵 생성은 기존 dev/maps 템플릿·생성 방식에 맞춰 추가한다. 기존 maps3·4·5 생성물만 고쳐 재생성 시 변경이 사라지지 않게 한다.
- 데이터 JSON의 Q24·badge_5 등은 기획 식별자다. 실제 저장 플래그 q24·badge5·f_current 등으로 명시적으로 매핑한다. 기획 JSON을 기존 엔진이 그대로 읽는다고 가정하지 않는다.
- 신규 몬스터 key와 도감 no를 모두 추가하고 #901–909 지역 개체는 유지한다. #091–102를 그 개체들의 도감 번호로 재활용하지 않는다.
- 기존 스타팅 진화 이름은 잎맥/숲맥, 불뿔/화산양, 물결뚱/너울뚱이다. 예전 문서의 미정 네이밍 메모로 되돌리지 않는다.
- 물은 특수·드래곤은 물리인 기존 판정을 유지한다. 신규 타입·특성·기술별 카테고리 개편을 이번 기획에 묶지 않는다.
- 보호 장비는 소유 확인 후 자동 적용하는 핵심 자료다. 전투 기술 슬롯이나 별도 장비 화면에 노출해 선택을 요구하지 않는다.

## 컨셉아트 적용

assets/monsters-091-096.png 및 assets/monsters-097-102.png는 내장 이미지 생성 도구로 만든 컨셉 시트다. 번호·실루엣·색·계열의 진화 연속성을 기준으로 앞/뒤/미니 도트를 제작한다. 시트 자체를 통째로 스프라이트 아틀라스로 간주하거나 불규칙하게 잘라 최종 도트로 쓰지 않는다.

시트의 각도에서 가려진 다리·지느러미 수는 문서 기준으로 정리한다. 찰칵게·제방집게는 보행 다리 4개+집게 2개, 환기둥은 얼굴 1개다. 실해마의 잎 지느러미는 전체 실루엣을 우선하며 작은 장식 수를 게임 플레이 규칙으로 취급하지 않는다.

최초 포획 등록·미포획 실루엣 정책을 #091–102에도 유지한다. 지원 대여로 도감을 포획 완료 처리하지 않는다. 테스트 편의의 디자이너 미리보기는 사용자 기본값으로 켜지 않는다.

## 순서

1. 2장 완료 저장을 불러와 R12→M07→M08→M09→R18의 간단 지형·이벤트와 무료 귀환을 잇는다.
2. 지도·입장 허가·F08·F09·대여 지원·퍼즐 초기화를 구현한다. Q25 지도를 수락 때 먼저 주고 Q30_start·Q31_start를 완료 뒤로 미루지 않는다.
3. 몬스터·출현표·학습표·진화·교본 복습·5·6관장을 붙인다. 수치는 플레이테스트 초안이며 조정 근거를 기존 docs/balance-and-decisions.md에 기록한다.
4. SQ3-01~08을 개별 플래그로 추가한다. 메인 상태를 덮어쓰지 않도록 선택 완료 후 변화만 합성한다.
5. 도트·대사·지역 변화·음향·모바일 조작을 다듬고, 현재 장 안내·저장 코드·구버전 저장 이전을 검증한다.

## 통과 기준

- 실제 기존 2장 완료 저장 3종(스타팅별)으로 R12에서 바로 이어지고 배지·동료·도감·지도·서브 의뢰가 보존된다.
- 메인 필수 지도는 조사 동선 전 지급되며 숨은 방·미방문 골목·도감 미포획 모습이 미리 노출되지 않는다.
- 새 포획 0회·소지금 0·3장 선택 의뢰 전부 생략 상태에서 메인 기술·지역 이동·교통 해금이 가능하다.
- 전투 통과는 별도로 스타팅별 실제 팀·도착 레벨·회복 소비·패배 횟수를 기록한다. 기존 물 스타팅 단독 4관장 미해결 메모를 완료로 바꾸지 않는다. 3장에서도 단독 진행을 보장하려면 실제 전투 검증 후 수치를 조정한다.
- 퍼즐 중 저장/재시작/패배/구조/초기화 후에도 막힘·동료 위치 유실·보상 중복이 없다.
- 물판에 탄 채 지도·지원 호출·메뉴를 열거나 구조해도 승하선 상태가 어긋나지 않는다. 급류와 바다와 폭포를 구별한다.
- 서브 의뢰 8개는 각자 시작·도중 저장·완료·재대화·기존 교본 중복 보상·이미 메인을 끝낸 상태를 확인한다.
- 맵 연결 검사·전체 1~3장 회귀·새 도감 진화·모바일 터치를 확인한다. 실제로 실행한 항목과 아직 못 한 항목을 구분해 결과를 남긴다.
