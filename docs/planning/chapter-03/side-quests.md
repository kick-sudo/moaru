## SQ3-01 돌아오지 않은 부표

- **주는 인물:** 해무나루 구조대장 가온.
- **시작 조건:** Q24.
- **동선·재방문:** 이미 지난 R13의 짧은 해변을 지도 MAP09에서 다시 찾아감.
- **등장 동료:** #91·#92.

1. **M07:** 구조대에서 포말이가 물고 온 끊어진 부표 끈을 관찰한다.
2. **R13:** 이미 건넌 해변의 걸린 부표를 바위 뒤에서 발견해 F07로 접근한다. 정해진 두 고리에 끈을 다시 건다.
3. **M07:** 구조대에 알리고 물 위에서 포말이가 새 부표를 따라 돌아오는 모습을 본다.

- **확정 보상:** 조사증표 1개·회복열매 3개.
- **완료 후 변화:** 해변에 복구한 부표가 남고 포말이 무리가 쉬는 장면 추가. 메인 항로 경계·급류 기술은 열지 않음.
- **막힘 방지:** 포말이를 잡거나 소유할 필요 없음. 구조대 공용 동료가 연출함.
- **예상 분량:** 8~12분. 실제 시간 미검증.

## SQ3-02 조개가 고른 모래

- **주는 인물:** 해무나루 관찰원 보라.
- **시작 조건:** Q24.
- **동선·재방문:** 동굴 진입 전에도 완료 가능. 실시간 썰물·Q25·F08 불필요.
- **등장 동료:** #93·#94.

1. **M07:** 세 조개 군락의 껍데기 문양과 주변 모래를 비교해 달라는 의뢰를 받는다.
2. **R13:** 안전 해변의 고정 관찰점 세 곳에서 모래의 굵기와 껍데기 층무늬를 기록한다. 포획·전투 없음.
3. **M07:** 보라와 기록을 맞추고 관찰소의 모래꼼이 물결돌로 진화하는 시연을 선택해서 본다.

- **확정 보상:** 무료 물결돌 1개·조개 관찰 수첩 기록.
- **완료 후 변화:** 관찰소에 보루패 시연 개체 등장. 플레이어 동료는 자동 진화하지 않음.
- **막힘 방지:** 오답은 힌트를 받고 즉시 다시 비교. 돌은 퀘스트 확정 보상이고 랜덤 채집이 아님.
- **예상 분량:** 10~15분. 실제 시간 미검증.

## SQ3-03 쉬는 시간도 일

- **주는 인물:** 푸른숨시 정화사 은서.
- **시작 조건:** Q26.
- **동선·재방문:** 센터·부두·휴식대의 짧은 왕복. D10 입장 없이 완료.
- **등장 동료:** #99·#100.

1. **M08:** 쉬러 나온 진득이와 작업자의 인터뷰를 공개 휴식대에서 듣는다.
2. **M08:** 휴식대 옆 그늘막과 안내판 자리를 정한다. 바람·그늘 표식을 읽고 수동 손잡이로 배치하며 언제든 되돌릴 수 있다.
3. **M08:** 공용 동료와 작업자에게 동선이 편한지 확인하고 휴식 안내판을 단다.

- **확정 보상:** 조사증표 2개·맑은숨 교본(이미 있으면 조사증표 1개로 대체).
- **완료 후 변화:** 의자·그늘막·휴식 시간 안내판·추가 시민 대사. Q27 수로 복구 상태와 별도 플래그.
- **막힘 방지:** 진득이 포획·독 상태 치료약 소비·소지금 필요 없음.
- **예상 분량:** 8~12분. 실제 시간 미검증.

## SQ3-04 바람이 멈춘 골목

- **주는 인물:** 푸른숨시 환기 담당 리오.
- **시작 조건:** Q27.
- **동선·재방문:** 처음 지나친 도시 골목·옥상 보행 데크.
- **등장 동료:** #101·#102.

1. **M08:** 공개 골목의 종이 바람표 3개 중 흐름이 약한 하나를 찾는다. 색뿐 아니라 깃 방향·움직임·문양이 다르다.
2. **M08:** 계단으로 올라가 수동 환기 덮개의 이물질을 치우고 두 손잡이 방향을 맞춘다.
3. **M08:** 후욱이가 같은 자리를 돌지 않고 옆 통풍탑으로 이동하는지 관찰한다.

- **확정 보상:** 조사증표 2개·회복열매 3개.
- **완료 후 변화:** 한 골목의 바람표가 움직이고 후욱이 순찰 경로 변화. 정화소·체육관 잠금 조건은 그대로.
- **막힘 방지:** 자력 맞춤·독 동료·새 특성·기체 흡입이나 불로 제거하는 행동 없음.
- **예상 분량:** 8~12분. 실제 시간 미검증.

## SQ3-05 강 건너 같은 표지

- **주는 인물:** 기억나루 관리인 해솔.
- **시작 조건:** Q29·Q17.
- **동선·재방문:** 2장 기억나루에서 미리 보았던 급류 경계 회수.
- **등장 동료:** #88·#90.

1. **M05:** 새 급류 수업을 듣고 돌아오면 강 건너 옛 표지 이야기가 추가된다. 기존 길비나침반 안내를 다시 받을 수 있다.
2. **M05:** 지금껏 못 건넌 표시 급류를 F08로 건너 표지의 문양을 관찰한다. 첫 안전 하선점에 구조 요청 지점이 있다.
3. **M05:** 표지와 복원한 지도의 같은 마을 이름을 맞춰 해솔에게 기록을 보여 준다.

- **확정 보상:** 조사증표 3개·옛길 수첩 삽화.
- **완료 후 변화:** 확인한 강 건너 길만 MAP06에 기록하고 표지를 보수. 상회 본부·미방문 도시로 우회시키지 않음.
- **막힘 방지:** 숨솜·밤누리 포획 불필요. 안개 정령은 옛길의 울림에서 태어난 생물로 유지.
- **예상 분량:** 10~15분. 실제 시간 미검증.

## SQ3-06 도착했다는 짧은 편지

- **주는 인물:** 해무나루 우편 담당 누리.
- **시작 조건:** Q24.
- **동선·재방문:** M07→M09는 메인과 함께 진행, 반환은 무료 교통 개방 뒤.
- **등장 동료:** #63.

1. **M07:** 돌바퀴시에서 일하는 가족에게 보낼 편지를 받는다. 목적지 이름만 알려 주며 미방문 도시를 지도에 밝히지 않는다.
2. **M09 · Q30:** 메인 동선을 따라 도착한 도시의 공개 적재장 작업자에게 전달하고, 쉬는 시간에 쓴 답장을 받는다.
3. **M07 · Q31:** 무료 화차·정기선으로 돌아와 답장을 전한다. 휴식·안부를 전하는 짧은 대사 선택은 보상에 차이를 주지 않는다.

- **확정 보상:** 조사증표 2개·500원·답장 수첩 기록.
- **완료 후 변화:** 양쪽 주민 대사가 바뀌고 M07 우편함에 새 편지 소품 등장.
- **막힘 방지:** 기한·발송 비용·현실 시간 대기 없음. 편지 보관은 파티·가방 소모 슬롯을 차지하지 않는 핵심 자료.
- **예상 분량:** 추가 이동 5~8분. 실제 시간 미검증.

## SQ3-07 오래된 돌의 자리

- **주는 인물:** 바람나루 창고지기.
- **시작 조건:** Q33·F09.
- **동선·재방문:** 초반 큰 바위의 재방문 표식을 6배지 뒤 회수.
- **등장 동료:** #70·#96.

1. **M01:** 초반 창고 뒤에서 보았던 큰 고리무늬 바위를 새 기술로 옮길 수 있다는 대사를 듣는다.
2. **M01:** F09로 운반석을 정해진 받침에 옮겨 작은 보행 샛길을 연다. 동료·주인공이 끼면 초기화·구조 귀환 가능.
3. **M01:** 옛 창고 기록함을 확인하고 길지기 초원도에 직접 걸은 샛길을 추가한다.

- **확정 보상:** 바위떨구기 교본(이미 있으면 조사증표 2개)·조사증표 1개.
- **완료 후 변화:** 창고 뒤 짧은 샛길 영구 개방·초반 주민의 성장 반응. 배지·지역 관문을 우회하지 않음.
- **막힘 방지:** 초반 지도 조각을 놓쳤어도 창고지기가 안내한다. 대여 산받곰 사용 가능.
- **예상 분량:** 8~12분. 실제 시간 미검증.

## SQ3-08 잡지 않아도 남는 기록

- **주는 인물:** 해무나루 낚시 안내원 마루.
- **시작 조건:** Q24.
- **동선·재방문:** 안내도 받은 직후 해안의 갈림길을 천천히 살펴보게 함.
- **등장 동료:** #93·#95·#97.

1. **M07:** 포획 대신 서식 환경을 기록하는 수첩 의뢰를 받는다.
2. **R13:** 바다·해변·관찰소 수조 중 고정 관찰점 세 곳에서 실해마·모래꼼·찰칵게의 설명을 읽는다. 실제 조우·포획과 무관하게 기록 가능.
3. **M07:** 물살·껍데기·집게의 쓰임을 안내원에게 보여 주고 낚시 구역 설명을 듣는다.

- **확정 보상:** 조사증표 3개·낚시 관찰 스탬프(수첩 기록).
- **완료 후 변화:** 낚시 게시판 설명이 늘어남. 조우표·희귀 확률·미끼 소비·낚싯대 해금은 변경하지 않음.
- **막힘 방지:** 기본 낚싯대·rod2·추가 포획을 요구하지 않음. 신규 코스의 낚시는 기존 rod2 소지로 즉시 가능.
- **예상 분량:** 8~12분. 실제 시간 미검증.

## 공통 구현 기준

- 같은 지도에 메인·선택 표시를 따로 두되 의뢰 목록에 새 시스템 용어를 과하게 노출하지 않는다. 주민과 대화→수첩의 선택 의뢰→단계별 목표로 연결한다.
- 첫 섬마을에서 MAP09를 받은 뒤 SQ3-01·02·08이 갈라진다. 지도 없는 시작 지역에 새 왕복 의뢰를 몰아넣지 않는다.
- 이미 가지고 있는 일회성 교본은 위에 적은 조사증표로 대체한다. 보상 완료 플래그를 먼저 확인해 반복 지급을 막는다. 중복 교본을 한 번 더 배웠다고 전투 기술 4칸을 강제로 바꾸지 않는다.
- 의뢰에 쓰는 편지·관찰 기록·답장은 버리기·판매 불가인 수첩 자료다. 몬스터를 상자에 보내거나 진화시켜도 의뢰를 실패시키지 않는다.
- SQ3-03의 쉼터 소품과 Q27의 수로 상태는 별도 기록이다. 한쪽을 먼저 끝내도 다른 장면이 덮어쓰지 않는다.
- 선택 의뢰를 하나도 하지 않은 저장으로도 Q24~Q33·F08·F09·MAP09~12·공공 이동을 모두 얻어야 한다.
- 현재 게임에 없는 외형 장비·낚시 확률 보너스·실시간 일과·주민 호감도 시스템은 이 보상의 전제에 넣지 않는다. 스탬프·삽화는 기존 수첩 설명의 추가 기록이다.
