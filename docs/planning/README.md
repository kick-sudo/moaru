- **기획·원본 제작:** 태양의 삼족오 금오와 달의 구미호 월백(가칭). [특징·미술 기준](legend-stories/character-specs.md).
- **인게임 원본:** 정면·뒷면 투명 캐릭터 PNG 4장. 태양·달·구름·산 배경은 포함하지 않는다. 실제 도트/미니·게임 적용은 대기.
- **서사:** 1~3장 장면 8개, 6배지 뒤 선택 의뢰 2개·성역 2곳, 관찰/포획/재도전·기존 저장 규칙. [구현 요청](legend-stories/implementation-handoff.md).

## 기존 3장 묶음 · CH3-001

- **기획 완료:** 해안→정화시설 도시→운송도시, 5·6관장, F08·F09, 지도 4개, 몬스터 #091–102와 컨셉 시트 2장, 서브 의뢰 8개.
- **구현 상태:** 시안 빌드로 구현(2026-10-22). 구현한 내용과 실제로 실행한 테스트 결과, 아직 확인하지 못한 것은 [3장 구현·검증 기록](chapter-03/implementation-status.md)에 나눠 적었다. 밸런스 메모와 정한 점(스타팅 단독 진행은 설계 목표가 아님 — 기획자 결정)은 [구현 메모](../balance-and-decisions.md).
- **클로드 시작 문서:** [구현 요청·통과 기준](chapter-03/implementation-handoff.md).
- **다음 미기획 구간:** R18 높은물길 이후, 폭포·상회 본부·7~8관장·#103 이후.
- **유지할 기존 결정:** #901–909 별도 지역 개체, 현재 스타팅 진화 이름, 탐험 기술과 전투 4칸 분리, 무료 지원 호출, 지도 점진 공개, 미포획 도감 실루엣.

기획을 추가할 때는 이번에 바뀐 내용·충돌하는 기존 결정·구현 요청을 같은 묶음에 기록한다. 구현자가 완료 항목과 실제 검증 결과를 갱신한다. 기획 문서 추가만으로 구현 완료라고 표시하지 않는다.
