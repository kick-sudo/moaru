## 초기 모델 제외 정리

사용자 요청에 따라 초기·중간 시안을 제작 기준에서 제외했다. 원본 목록의 canonicalAssets는 최종 앞·뒤 PNG 네 장과 일치하며 파일과 문서 링크가 존재한다. 작업 폴더의 이전 금오 시안과 오래된 점검 스크립트도 삭제했다. 게임에 남은 초기 DRAW.geumo는 클로드 구현 때 최종 외형으로 교체할 대상으로 명시했다.

- 두 전설·장면 8개·의뢰 2개·성역 2곳의 식별자와 상호 참조를 검사했다.

- 메인 진행 조건을 새로 쓰지 않으며, 관찰과 포획을 분리하고 두 의뢰의 순서를 고정하지 않았다. 모든 장면에 생략/회상 경로를 둔다.
