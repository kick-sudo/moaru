# 모아루 · 태양과 달의 전설 LGS-001

**최종 디자인 기준 확정 / 게임 적용 대기** / 2026-10-22

제작 기준은 아래 네 장으로 확정한다. 초기 모델·중간 시안·배경 포함 시안은 제작 참고와 선택 목록에서 제외한다.

사용자 참고 이미지와 수정 요청을 반영한 한 쌍의 전설이다. **금오의 긴 날개·긴 꼬리·날렵함·화려함**, **달을 상징하는 아홉 꼬리 구미호**를 같은 화풍으로 맞춘다.

| 전설 | 특징 | 이야기의 역할 |
|---|---|---|
| L01 금오 · 불/비행 | 먹빛·남청 깃, 금빛 문양과 불꽃, 세 발, 거대한 긴 날개, 긴 눈무늬 꼬리깃 세 줄 | 낮의 길을 밝히고 출발을 상징 |
| L02 월백(가칭) · 에스퍼/고스트 | 진주빛·은빛 털, 푸른 눈, 은빛 문양, 청보랏빛 달불과 아홉 꼬리 | 밤의 귀로를 비추고 돌아오는 여정을 상징 |

**인게임 원본은 배경 없는 투명 PNG다.** 태양·달·구름·산을 캐릭터 그림에 포함하지 않는다. 고해상도 원본과 작은 게임용 도트/미니 제작은 구분한다.
