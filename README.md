# 모아루: 잠든 길의 노래

DS(두 화면 휴대용 게임기) 감성의 몬스터 RPG **시안 빌드**입니다.
세계관·장 기획·몬스터 디자인은 기획자(이 저장소 주인)가 문서로 작성했고, 플레이 가능한 게임은 Claude가 그 문서를 바탕으로 구현했습니다.

- 순수 HTML5 Canvas + JavaScript — 빌드 도구·외부 라이브러리 없음
- 256×192 픽셀 화면 두 장 (위: 게임 화면 · 아래: 터치/메뉴 화면). 휴대폰은 위아래, 넓은 화면은 좌우 배치
- 현재 범위: **1장 ~ 3장** (관장 6명, 도감 102종 + 지역 몬스터 9종)

## 실행

`index.html`을 브라우저로 열면 바로 실행됩니다 (서버 필요 없음).

- 조작: 방향키 이동 · **Z** 결정 · **X** 취소 (누른 채 이동하면 달리기) · **Enter** 메뉴
- 휴대폰: 아래 화면의 십자키와 A/B 버튼
- 저장: 브라우저 저장소 + 설정의 "저장 코드"로 다른 기기에서 이어 하기

## 검증

자동 플레이 봇이 실제 이벤트 스크립트를 따라 스타팅 3종 모두로 1장·2장 끝까지 통과하는지 확인했습니다. 3장은 봇이 만든 실제 2장 완료 저장(스타팅 3종)을 불러와 R12에서 이어 가며 확인했습니다. 자세한 결과는 [`docs/balance-and-decisions.md`](docs/balance-and-decisions.md)와 [3장 구현·검증 기록](docs/planning/chapter-03/implementation-status.md)에 있습니다.
